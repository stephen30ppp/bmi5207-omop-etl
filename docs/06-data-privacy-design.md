# 06 · 去标识化设计

## 1. 定位：这是 pseudonymisation，不是 anonymisation

这套方案保留了稳定的 ID 映射和每名患者固定的日期偏移，所以属于**假名化**。持有 secret 和对照表的人可以还原原始数据。只有 5 名患者，k-匿名无从谈起。数据本身是合成数据，报告需要如实写明这一点和残余风险。

## 2. 风险清单（已核实）

| 类别 | 字段 | 处理 |
|---|---|---|
| 直接标识符 | 无（没有姓名、NRIC、电话、地址） | — |
| 源系统 ID | Patient_No（5 个）、Case_No（visit 21 个 + lab 5 个，共 26 个） | 替换成整数 ID；原值不出现在输出中 |
| 精确时间 | 全部 datetime | 每名患者统一偏移 d 天 |
| 年份 | 出生年、死亡年 | 用同一个 d 通过年中锚点偏移 |
| 准标识文本 | 科室、病房、子专科、Dis_Reason、Order_Text | 不输出 |
| 罕见临床组合 | 诊断、手术 | 保留，因为这是分析需要的数据；在报告中说明残余风险 |

## 3. 算法

```
secret          ← 从仓库之外的文件读取（不进 git）；评阅者使用随交付物附带的 demo_secret
h(ns, x)        = HMAC_SHA256(secret, ns + ":" + x)

person_id       = rank(h("person", Patient_No)) among 5    → 1..5，与源文件顺序无关
visit_id        = 中央 allocator，按 (person_id, 偏移后 start, h("visit", Case_No)) 排序 → 1..21
lab_episode_tok = "E" + h("episode", lab Case_No)[:8]      → 只写入可共享的 lineage

d(p)            = sign × (30 + h("shift", p) mod 336)      → ±[30, 365] 天，sign 取自 HMAC 的另一位
shift_dt(p, t)  = t + d(p)                                 → 时、分不变，所有间隔不变
shift_year(p,Y) = year( date(Y, 7, 2) + d(p) )             → 与 datetime 共用同一个 d
death_date      = 12-31 of shift_year(p, Death_Year)       → 先偏移年份，再补 12-31
```

**为什么用年中锚点**：如果先把年份补成 12-31 再加 d，知道这条约定的人可以直接从死亡日期反推出 d（A 指出的问题）。用 7-02 作锚点后，年份的变化量 Δy ∈ {-1, 0, +1}，年龄误差不超过 1 岁，与源数据只到年份的精度一致。同时只用了一个 d，回应了 B 对“两套规则”的批评。

**在本数据上证明“死亡 ≥ 最后事件”**：最危险的患者是 Patient-4，最后事件 2016-12-17，死亡年份 2017。
- d ∈ [30, 182]：Δy = 0，死亡日为 2017-12-31，最后事件最晚 2017-06-17。
- d ∈ [183, 365]：Δy = +1，死亡日为 2018-12-31，最后事件最晚 2017-12-17。
- d < 0 时同理成立。

患者 Patient-1 的死亡年份是 2018，比最后事件晚两年，不会出问题。测试 T-DATE-3 对每一个 secret 都会自动断言这一点。

**闰日**：按天偏移不会产生 2 月 29 日回退的问题。B 的整年偏移在 `Case-4-04` 的出院时间 2016-02-29 上必然出错，因此不采用。

## 5. 验证（见 09）

- T-DEID-1：在所有输出文件中搜索 5 个 Patient_No、26 个 Case_No，以及全部原始 datetime 字符串，命中数必须为 0。
- T-DEID-2：同一个 secret 跑两次，输出逐字节相同；换一个 secret，ID 和日期都会变。
- T-DATE-1、2、3：同一患者任意两个事件的间隔不变；|d| ∈ [30, 365]；死亡 ≥ 最后事件，出生年 ≤ 所有事件的年份。

## 6. 报告中必须写明的局限

- 这是 pseudonymisation，持有 secret 可以还原。
- 日历上的季节和年份趋势被打乱，**不适合做季节性或年度流行病学分析**。
- 时、分和星期几**不保证**保持。
- 罕见的诊断和手术组合仍有被识别的可能，但数据是合成的。
